# 经纬万象 · Terra Mosaic

探索自然与人共同塑造的世界。发现有鲜明特色的山川、海岸、城市、建筑与文化景观，沿着路线找到值得亲自去看的地方。

本项目的仓库名仍为 `world-travel-map`。品牌采用折叠地图标志、矿物蓝与暖白界面，少量赭红连接自然与人文；真实照片、画作和各主题的内容特色保持独立。品牌规范见 [TERRA-MOSAIC-DESIGN.md](TERRA-MOSAIC-DESIGN.md)。

当前版本包含 **37 个主题、1,703 条地点记录和 121 个行程方案**。采用 Canvas 2D 球面正射投影，无需地图 API 密钥和前端构建；底图与原有影像随项目本地提供。新增特色公路照片暂使用带作者与许可标注的 Wikimedia 缩略图外链，需联网访问。

## 快速开始

在仓库根目录运行：

```sh
python3 -m http.server 8000
```

打开 [http://localhost:8000](http://localhost:8000)。请通过 HTTP 访问，不要直接双击 `index.html`；文件协议会限制地图数据读取。

### 路线语义

- **有序走廊（`route`）**：按精选站点顺序显示示意连线，不等于连续可通行的步道或真实道路。
- **文化网络（`network`）**：地点没有固定交通顺序，不绘制虚构的连续路线，也不提供误导性的“全程里程”。
- **闭环（`loop`）**：最后一站显式回到起点；直线距离计入闭环一段，收藏不会重复起点。

徐霞客主题将六次不同年份的旅次分开，不把一生游踪拼成一次徒步；马可波罗主题区分记述与不确定线索，不把书中提及视为亲访证明。印象派与莫扎特主题也不冒充单次历史旅行。

中山道全线是历史走廊，木曾保存步道另作分段体验；Via Francigena 不混入意大利南延；大运河不是 UNESCO 大运河全部隋唐及浙东水系。法国之路选用 Triacastela 至 Sarria 的 San Xil 分支，不把其他分支串行叠加。66 号公路历年有改线，圣莫尼卡码头作为当代象征，不声称唯一原始终点。

## 特色公路主题

公路内容拆成 12 张独立主题地图，在首页“公路旅行”分类统一发现；每张地图有自己的封面、地域、视角和所属行程。原来的 16 个方案与 88 个地点均保留：G219、G331、G228 全国概览采用不连线的地点网络，另有阿里、鸭绿江和胶东三条区域行程；海外覆盖加州 SR1、佛罗里达 US1、犹他 SR12 与 Mighty 5、加拿大北冰洋公路、挪威大西洋之路、冰岛环岛、大洋路、Milford Road 与南非花园大道。

原 `#theme=roads` 链接会跳到首页的“公路旅行”集合；包含具体行程或点位的旧链接会跳到对应新主题。地点和行程 ID 不变，已有收藏保留。

加拿大路线为 Dempster 接 Inuvik–Tuktoyaktuk，不是 Yonge Street。中国全国总览不声称已全线连续通行；支线、季节、渡河与封路条件见逐条说明。[完整研究及边界](ROAD-TRIPS.md)。

新增 13 项实景照片只绑定到相应地点，保留作者、来源和许可。当前为远程缩略图，跨境可达性和第三方服务仍可能影响加载；不与已有本地影像混称。背景资料核对不等于实时路况认证。

## 怎么使用

1. 首页推荐轮播覆盖中山道、大运河、印象派、维京、NC500 与美国国家公园，点击进入对应主题或行程。在首页搜索主题、地点、画家或行程；组合文化兴趣与地域筛选，在“主题地图”与“精选行程”之间切换。
2. 打开主题，进入“地图探索”“推荐行程”或“我的旅程”。
3. 搜索地点，按分类、区域或国家筛选；点击列表、地图点位或文字标签阅读详情。
4. 选择月份和可用天数，预览推荐行程，再逐站查看；关闭详情会保留当前路线。
5. 收藏单个地点或整条行程，在“我的旅程”查看、移除或逐站播放。

拖拽旋转地球，滚轮、双指或按钮缩放；键盘方向键旋转，`+` / `-` 缩放。预览行程时地图仅展示该行程的地点，可返回主题全图。

主题、面板、行程、地点和筛选条件保存在 URL 片段中，支持刷新及浏览器前进、后退。收藏按稳定地点 ID 保存在当前浏览器的 localStorage，重复加入会去重，预览不会覆盖收藏。无坐标地点仍可搜索、阅读和收藏，以“待补坐标”标识，不参与地图连线和播放。

### 首页推荐轮播

轮播每 8 秒自动切换，悬停、键盘焦点位于轮播内、页面隐藏或轮播滚出视野时暂缓。系统启用 `prefers-reduced-motion` 时不自动播放。已移除可见播放、圆点和前后切换按钮，保留推荐的进入入口。

键盘可用方向键切换，`Home` / `End` 到首尾；手动切换后保持暂停。在轮播区域按空格暂停或恢复，Escape 停止。自动切换不移动焦点、不触发读屏播报。

### 地点列表与可调侧栏

地点卡片保留独立间距，长名称在卡片内换行。桌面可拖动侧栏与地图之间的分隔条调整宽度，宽度会保存在当前浏览器；左右方向键也可调整，按住 Shift 加快，双击或 Enter 恢复默认。窗口较窄时会限制最大宽度，为地图和详情保留空间；手机保留上下布局。

### 行程封面与内容审计

首页行程封面按该行程实际站点绑定，不再回退到主题封面。当前121个行程方案中114个有对应地点影像、7个显示中性地点导览卡（本批原有95条为89/6，另外保留已合并的特色公路与四个文化主题）；同一照片只有在对应地点确实出现在行程中时才可复用；多图可选时优先分散不同站点画面。主题地图封面仍是主题代表影像。精确国家搜索和行程地域筛选也按实际地点判断。

[内容与封面审计](qa/content-audit.json)已同步最新公路扩展，覆盖1,703条记录、121个行程方案及其中453个地点：空介绍和完全重复介绍均已清零。详情移除了与地区、类型重复的字段及通用提示，保留原始数据和出处；453个行程地点可直接打开相关行程。本轮细化安第斯10个点位，补齐黄石、塞巴斯蒂亚简介，并分别说明红杉与国王峡谷。

该审计是结构和编辑质量检查，不代表逐项重新核验所有历史事实。最新全量清单有343条短概述（其中287条在推荐行程中）；117处已经有展开内容，短且没有分层说明的候选为226处，其中175处在推荐行程中，短并不自动意味着错误；Desaguadero–Titijoni 与 Tiwanacu 两段的现场构筑物说明仍待专门资料。

### 运行检查

在仓库根目录运行，无需浏览器的单元与语法检查：

```sh
node --test tests/*.test.cjs
for file in *.js scripts/*.cjs tests/*.cjs; do node --check "$file" || exit 1; done
```

浏览器与 DOM 检查额外需要 Node.js 能解析 `playwright`、`jsdom`，浏览器检查还需要可运行的 Chromium。例如先安装测试依赖：

```sh
npm install --no-save --package-lock=false playwright jsdom
```

运行完整浏览器检查套件：

```sh
node scripts/run-browser-suite.cjs
```

该命令自动启动 8000 端口的测试服务，请先停止占用该端口的手动预览。默认 Chromium 路径为 `/usr/bin/chromium`，可通过 `CHROME_PATH` 指定；`PLAYWRIGHT_MODULE` 可指定 Playwright 模块路径。也可传入单个脚本：

```sh
node scripts/run-browser-suite.cjs check-editorial.cjs
node scripts/check-dom.cjs
node scripts/check-carousel.cjs
node scripts/check-sidebar.cjs
node scripts/audit-content.cjs
```

`qa/preview.html` 可在 HTTP 预览中切换 1440×1000 与 390×844 的真实 iframe CSS 视口。这是响应式浏览器检查，不是手机实机测试。
