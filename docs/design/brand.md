# 经纬万象 · Terra Mosaic

## 产品表达

探索自然与人共同塑造的世界。路线把有鲜明特色的自然景观、城市、建筑、艺术与文化地点组织成可以探索的内容。自然与人文具有同等地位；文化故事是理解地方的线索，不是地图存在的唯一理由。

仓库仍使用 `world-travel-map`，不改动外部地址或已有收藏键。品牌英文固定写作 **Terra Mosaic**，不采用音译或单独的 Atlas 作为产品名。

## 标志

`assets/brand/terra-mosaic.svg` 为三色矢量标志：折叠地图中的山川与建筑，由一条路线连接。小尺寸使用 `assets/brand/favicon.svg`，减少折线与细节。网页通过本地 SVG 加载，不依赖生成服务或远程图片。

图标概念经过图像生成探索；交付网页使用重新整理的简洁矢量几何。不要把素材中的亭台、山峰或桥梁当作特定地点的真实地貌。

## 色彩与排版

| 角色 | 色值 | 使用 |
| --- | --- | --- |
| 页面纸色 | #F7F6F2 | 页面、侧栏、页脚 |
| 卡片 | #FFFFFF | 输入、详情、需要区隔的内容 |
| 墨色 | #252D2D | 主要文字 |
| 次级文字 | #606C6D | 说明、元数据 |
| 矿物蓝 | #245A69 | 品牌、主操作、选中状态 |
| 赭红 | #B7553D | 标志路线、焦点提示和少量强调 |
| 浅色交互面 | #EDF3F3 | 悬停、已收藏和轻量分组 |

颜色集中定义于 `terra.css` 的 `--tm-*` 变量。品牌主色与各地图主题的 `--accent` 分开；真实影像、画作不叠品牌滤镜，地图保留主题的地理阅读方式。

正文使用系统无衬线字体；少量标题使用系统衬线字体。正文、来源、站点元数据分别建立清楚层级，避免用大量微小文字填充卡片。手机输入框使用 16px 字号以避免系统自动放大。

## 共享界面

- 首页：品牌和探索定位、主题轮播、自然/艺术/城市三种入口、兴趣与地域筛选、主题或行程结果。
- 首页推荐从现有主题池按探索兴趣搭配；新页面优先避开上次出现的主题，同一页面内保持稳定，封面不重复，完整画作在画框内展示。
- 首页轮播默认自动播放，鼠标悬停和键盘焦点停留时暂停。指针切换后可以继续自动轮播；离开主题返回首页仍可继续。减少动态效果时停用自动播放。暂停按钮仅在键盘聚焦时出现。
- 各主题保留影像与文化内容；操作、列表形状、编号和阅读层级一致。避免每条路线发明一套控件。
- 行程卡面优先展示该行程自身绑定的影像，不借品牌升级更换成不相关图片。
- 地点详情保留正文、作品/影像、相关路线、资料和来源分层；收藏操作与上一站/下一站固定在详情底部。
- 桌面保持可调侧栏；手机沿用地图与侧栏的上下布局，详情采用现有可滚动抽屉。

## 验证与边界

`scripts/check-terra-ui.cjs` 在 Chromium 中检查首页、筛选、所有主题进入、自然/人文/艺术主题、行程与点位、手机布局、刷新和收藏，并输出页面截图。`scripts/check-carousel.cjs` 使用受控时钟检查轮播行为。截图是实际运行结果，生成的配色概念图不作为浏览器验收证据。

本次只修改品牌及呈现方式，未增删地点、路线、作品或第三方素材许可；不宣称对现有数据的历史事实重新完成了全量考证。
