# 使用指南

[返回项目首页](../README.md) · [打开线上地图](https://raeqi.github.io/world-travel-map/)

## 发现值得去看的地方

首页可搜索主题、地点、人物、作品线索与行程，组合兴趣和地域筛选，并在主题地图与精选行程之间切换。当前入口以地域和内容组织，旧人物主题及原方案仍保留搜索和链接兼容；[主题目录](reference/themes.md)明确区分可见入口和兼容入口。

首页推荐每次载入会重新选取一组主题，兼顾自然、人文、艺术、古道和公路。同一页面内搜索或返回时保留当前组。轮播自动播放，悬停、焦点进入、页面隐藏或离开可视区时暂停；减少动态效果偏好会关闭自动播放。键盘方向键、Home / End 可切换，空格暂停或恢复，Escape 停止。

## 从地图到行程

1. 打开主题，在“地图探索”搜索地点，或按类型、区域、国家筛选。
2. 点击地点列表、地图点位或标签查看详情。可展开资料，查看相关作品与来源；完整图像入口保留作者和许可。
3. 在“推荐行程”按月份和可用天数选择方案，预览地点与路线，逐站打开详情。
4. 收藏地点或整条行程，在“我的旅程”查看、移除、逐站播放。重复收藏会去重。

当前主题、筛选、地点和方案记录在 URL 片段，支持刷新和浏览器前进、后退。收藏存于浏览器 localStorage，不会随 GitHub 更新写回仓库，也没有账户间同步。

## 交互与阅读

拖动地球旋转，滚轮、双指或缩放按钮调整视野；地图获得焦点时可用方向键、加减键。桌面侧栏分隔条支持拖动、左右方向键调宽，Shift 加快，Enter 或双击恢复默认；宽度存于当前浏览器。手机详情采用抽屉，关闭后回到原地图或路线。

图片阅览支持 Enter / Space 打开、Escape 关闭，并返回原焦点。图片失败时保留可用文字、来源和操作。名录代表坐标不是导航入口，未定位地点仍可通过列表阅读和收藏。

## 路线与作品如何理解

- 历史走廊和有序路线按所选节点示意，不承诺全程连续可通行。
- 文化网络关联作品、人物与地方，不冒充同一个人的一次旅行；徐霞客不同旅次、莫扎特不同年龄的访问分别阅读。
- 闭环方案最后回到起点，收藏去重；距离为球面直线，不作为驾驶或徒步里程。
- 作品的描绘地、创作关联地与现藏机构分别说明。现藏地点不等于画中地点，收录作品不保证当下展出。
- 大运河覆盖精选城市，泛美公路注明达连缺口；更具体的边界看各主题阅读及[路线资料](maps/README.md)。

资料和月份、天数是探索参考；开放、交通、越境和现场限制需要向管理机构确认。[内容质量报告](content-quality/README.md)列明已研究与未验收范围。
